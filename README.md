# 🛡 **Hero Apps** - A apps manage platform

**[Hero Apps](https://ph-hero-apps.netlify.app/)** is a streamlined platform designed to make application management effortless.  
From installing new apps to safely uninstalling unused ones, the system provides a clean, fast, and intuitive workflow.  
Built for simplicity and efficiency, Hero Apps ensures users can manage their software ecosystem with confidence and full control.

## ✨ Features

### 🌟 **Core Features**
- Clean and modern UI built with **Tailwind CSS** & **DaisyUI**
- Component-based architecture using **React**
- Smooth page navigation powered by **React Router**
- Fast bundling and hot reload with **Vite**
- Reusable UI components across the entire application
- Fully responsive design for mobile, tablet, and desktop

### 📊 **User Experience Enhancers**
- Animated charts & data visualization using **Recharts**
- Toast alerts for success/error actions with **React Toastify**
- Professional icons from **Lucide** & **React Icons**
- Loading animations and spinners for better UX

### ⚙️ **Developer-Friendly Features**
- Organized folder structure for scalability
- Code linting and formatting with **ESLint**
- Environment variable support via `VITE_`
- Easy-to-extend and customizable UI
